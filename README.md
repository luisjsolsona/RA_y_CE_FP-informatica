# RA y CE FP Informatica (Copia de seguridad de CATEDU)

Este repositorio contiene una copia de seguridad, generada el 30-07-2026, de la informacion publicada por CATEDU sobre los ciclos formativos, cursos de especializacion y el PEE de la familia profesional de Informatica y Comunicaciones (IFC): modulos profesionales, horas y sus Resultados de Aprendizaje (RA) y Criterios de Evaluacion (CE).

El archivo ciclos_informatica.html es una aplicacion web autocontenida (HTML/CSS/JS) que permite consultar y buscar esta informacion de forma local, sin conexion.

## Importante

Esta es una copia de seguridad NO OFICIAL y puede quedar desactualizada. Consulta siempre las fuentes oficiales antes de tomar cualquier decision academica:

- Fuente original: https://centrosdocentes.catedu.es/awc/public/pages/familias/ciclos.php?familia=IFC
- Portal oficial de Formacion Profesional: https://www.todofp.es/que-estudiar/grados-d.html
